¿Por qué es importante calcular FPS?

  • Experiencia fluida: 60 FPS en PC, 30-60 en móvil es el estándar de calidad
  • Diferencial competitivo: Juegos con mejor rendimiento ganan más usuarios
  • Optimización proactiva: Identifica cuellos de botella antes de que afecten usuarios
  • Planificación de features: Sabe cuántos efectos/polígonos puedes agregar sin perder rendimiento

📚 Guía de Optimización FPS

  • Reduce Draw Calls: Usa material batching, atlas de texturas, GPU instancing
  • Optimiza Geometría: Implementa LOD (Level of Detail), culling, simplificación de meshes
  • Shaders Eficientes: Usa forward rendering para pocas luces, deferred para muchas
  • Post-processing: Half-resolution o quarter-resolution para efectos pesados
  • Sombras Dinámicas: Limita distancia, reduce cascadas, usa shadow atlasing
  • Profiling: Usa Unity Profiler (CPU/GPU) para encontrar cuellos de botella reales
  • Targeting: Diferentes configs para diferentes dispositivos/plataformas
