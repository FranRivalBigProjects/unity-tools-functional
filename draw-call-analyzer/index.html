Why do Draw Calls matter?

  • CPU bottleneck: Every draw call has overhead. Reducing them is critical for FPS
  • Impact on all platforms: Especially on mobile where CPU is limited
  • Industry targets: PC: < 2000, Mobile: < 1000, VR: < 500
  • Maximum ROI: Optimizing draw calls is the first thing you should do before touching shaders

📚 Batching Techniques Guide

  • Static Batching: For immovable geometry. Combines meshes in memory. 🏆 Best quality/impact ratio
  • Dynamic Batching: For moving objects. Max 900 vertices per batch. Be careful on mobile.
  • GPU Instancing: Draws the same mesh multiple times. Perfect for trees, rocks, identical enemies.
  • Texture Atlasing: Combines multiple textures into one. Reduces material changes.
  • Frustum Culling: Does not render what you can't see. Unity does it automatically but verify it.
  • LOD Groups: Reduces polygons at distance. Big savings in draw calls.
  • Deferred Rendering: Better for > 10 dynamic lights. Forward for fewer lights.

🔧 Tools and References

  • Unity Profiler (Stats): Shows exact DCs. Window → Analysis → Profiler
  • Frame Debugger: Visualizes each DC. Window → Analysis → Frame Debugger
  • SetPass Calls: Shader changes. Optimize materials.
  • Batch Breakers: What breaks batches: material changes, textures, different scales (dynamic batching)
