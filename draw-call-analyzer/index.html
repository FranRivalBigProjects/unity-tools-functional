¿Por qué importan los Draw Calls?

  • Cuello de botella de CPU: Cada draw call tiene overhead. Reducir es crítico para FPS
  • Impacto en todas las plataformas: Especialmente en móvil donde CPU es limitada
  • Targets de industria: PC: < 2000, Móvil: < 1000, VR: < 500
  • ROI máximo: Optimizar draw calls es lo primero que debes hacer antes de tocar shaders

📚 Guía de Técnicas de Batching

  • Static Batching: Para geometría inmóvil. Combina meshes en memoria. 🏆 Mejor ratio calidad/impacto
  • Dynamic Batching: Para objetos que se mueven. Máximo 900 vértices por batch. Cuidado en móvil.
  • GPU Instancing: Dibuja el mismo mesh múltiples veces. Perfecto para árboles, rocas, enemigos idénticos.
  • Texture Atlasing: Combina múltiples texturas en una. Reduce cambios de material.
  • Frustum Culling: No renderiza lo que no ves. Unity lo hace automático pero verifica.
  • LOD Groups: Reduce polígonos a distancia. Grandes ahorros en draw calls.
  • Deferred Rendering: Mejor para > 10 luces dinámicas. Forward para pocos lights.

🔧 Herramientas y Referencias

  • Unity Profiler (Stats): Muestra DC exactos. Window → Analysis → Profiler
  • Frame Debugger: Visualiza cada DC. Window → Analysis → Frame Debugger
  • SetPass Calls: Cambios de shader. Optimiza materiales.
  • Batch Breakers: Lo que rompe batches: cambios de material, texturas, escalas diferentes (dynamic batching)
