Unity Asset Optimizer

Calculate and optimize the size of your textures, meshes and assets to improve performance

Why optimize assets?

  • Less memory consumption: Reduce RAM usage on mobile devices and consoles
  • Better performance: Faster load times and improved FPS at runtime
  • Faster downloads: Decrease bundle and APK/IPA size
  • Better experience: Less stuttering and lag during gameplay

🎯 Recommendations

📚 Resources and Guides

  • Texture Compression: Use ASTC for mobile (best quality/size ratio), ETC2 for basic Android, DXT1 for PC
  • Mipmaps: Always use for distant objects. Disable only for UI or close-up elements
  • Asset Bundles: Split your assets into small bundles for on-demand downloading
  • LOD Groups: Implement Level of Detail to reduce polygons at distance
  • Atlasing: Combine multiple small textures into one large one to improve batching
  • Profiling: Use Unity Profiler to monitor memory usage in real time
